# homebrew-tap

Homebrew tap for InterSystems ObjectScript tooling:

- [iris-dev](https://github.com/intersystems-community/iris-dev) — MCP server connecting AI assistants to InterSystems IRIS.
- [ascot](https://github.com/intersystems-community/ascot) — a static analyzer for ObjectScript.

## Install

```bash
brew tap intersystems-community/tap
brew install iris-dev
brew install ascot
```

## Upgrade

```bash
brew upgrade iris-dev
brew upgrade ascot
```
